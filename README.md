# xhs · 佳康顺小红书图文生成技能

> 基于产品白底参考图，一键生成5张3:4高清种草图 + 500字内爆款配文，三套视觉语言轮换，篇篇有新意。

## 功能

- **产品不变形**：基于白底参考图用图生图生成，严格保持产品外观
- **5张3:4高清图**：1536×2048，封面→卖点→场景→细节→CTA
- **爆款配文**：标题≤19字 + 正文≤500字 + 5个话题标签，含emoji
- **三套视觉语言**：实证档案风 / 暖纸手记风 / 奶油编辑风，自动轮换
- **文案软化**：无硬广标签，第一人称真实体验，结合场景痛点
- **自动归档**：产物按 `产品名_序号` 存入 `图文成片/`

## 核心规则

### 展开/折叠状态
- P1-P4：必须用**完全展开状态**（产品正面微侧，座椅/靠背/扶手/四轮清晰可见）
- P5：唯一一张**折叠状态图**（配手提包/购物袋做大小对比）

### 文案软化铁律
1. 图片左上角禁止硬广胶囊标签（"出行好物""核心卖点"等），改用手写感小字引入场景
2. 标题用痛点/故事/数字，不用产品名
3. 正文第一人称真实体验，结合具体场景和痛点
4. 测评清单型允许写1条小不足增加可信度
5. 结尾自然互动引导，不提价格/租赁/购买链接

## 使用方式

作为 Agent Skill 安装后，直接说：

> 用 xhs 技能生成一篇小福车的小红书图文，用暖纸手记风。

技能会自动：读取产品资料 → 上传白底图 → 选视觉语言 → 生成5张图 → 写配文 → 归档到 `图文成片/小福车_002/`。

## 合规红线

- 医疗器械类禁用"治疗/治愈/疗效"，用"辅助/康复训练/出行"
- 禁用极限词"最""第一""绝对"
- 默认软广不提及价格、租赁、购买链接
- 禁止站外引流（微信号/电话/二维码）
- 朋友2有备案号（苏苏械备20200005号），实证风可打信任牌

## 反AI感铁律

禁紫粉渐变 · 禁居中对称 · 禁全圆角浮卡 · 禁堆emoji · 强调色≤5% · 不用纯白纯黑 · 第一眼≥3:1尺度反差
